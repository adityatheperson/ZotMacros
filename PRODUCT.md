# ZotMacros
Native Android nutrition tracker for UCI students. Fuel your day. Track your macros.
Primary task: select a real dining-hall food, adjust servings, log it, and see accurate daily totals immediately.
Requirements: docs/REQUIREMENTS.md. No account. Local Room diary; real Anteater API menus; nullable nutrients; reliable offline history.
Platform: android; Kotlin/Compose/Material 3; min SDK 26. Target phone: Pixel 8 Pro.
Visual authority: user-approved docs/design/approved-mockup.png, lighter UCI blue and gold (not the original lime brief).
