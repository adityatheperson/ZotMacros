# ZotMacros iOS Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a native iPhone ZotMacros app with real dining menus, persistent local food logging, accurate nullable nutrition, and the approved blue-and-gold interface.

**Architecture:** A Foundation Swift package owns domain logic, parsing, networking, and repository contracts. The iOS application implements SwiftData persistence and a main-actor observable model, with SwiftUI views consuming that model. Android remains intact.

**Tech Stack:** Swift, Swift Package Manager, Foundation/URLSession, SwiftUI, SwiftData, UserDefaults, XCTest, Xcode.

**Spec:** `docs/superpowers/specs/2026-10-10-ios-port-design.md` (approved).

## Global Constraints

- Use SwiftUI with an iOS 17 minimum deployment target; place the iOS project under `ios/`.
- No additional hosted service, accounts, cloud sync, payments, advertising, or coaching.
- Preserve explicit nutrient units and reported zero values; missing, malformed, negative, or nonfinite nutrients are unknown.
- Serving quantities must be finite, greater than zero, and at most 1,000. No intermediate rounding.
- Use America/Los_Angeles for menu and diary dates, including foreground refresh and midnight rollover.
- Diary edits use the saved snapshot; one save is idempotent, later intentional additions remain possible.
- Persistence errors keep the sheet open; network failures never remove diary entries. Never silently reset unreadable data.
- Minimum 48-point primary interaction targets, Dynamic Type, VoiceOver, safe areas, and Reduce Motion support.
- No signing credentials, generated build output, or production fixture menus in source control.
- Preserve existing Android edits. Stage only files owned by these tasks.
- Full Xcode and an iOS simulator runtime are currently missing. Package tests can run first; native verification remains mandatory before claiming completion.

## Review Focus

- Rapid hall changes with a late first response: the selected hall retains its own result (Task 5).
- A save fails after an entry is staged: retry must persist exactly one entry and retain the sheet (Tasks 4 and 6).
- A cache payload cannot decode: preserve the diary and show a recoverable menu error (Tasks 3 and 4).
- Spring/fall daylight-saving transitions: campus dates and next-midnight refresh remain correct (Tasks 1 and 5).
- Accessibility text plus decimal keyboard: the food sheet's save action and validation remain reachable (Tasks 6 and 8).

## File map

- `ios/ZotMacrosCore/Package.swift`, `Sources/ZotMacrosCore/`: independently testable domain and remote repository implementation.
- `ios/ZotMacrosCore/Tests/ZotMacrosCoreTests/`: deterministic domain/parser/repository tests, with captured fixtures confined to `Fixtures/`.
- `ios/ZotMacros.xcodeproj/`: committed project, app/unit/UI test targets, shared `ZotMacros` scheme, local package reference.
- `ios/ZotMacros/App/`: entry point, dependency composition, observable state and lifecycle.
- `ios/ZotMacros/Persistence/`: versioned SwiftData schema, diary/cache adapters, preferences.
- `ios/ZotMacros/UI/`: theme, navigation, screens, shared components, food sheet and onboarding.
- `ios/ZotMacros/Assets.xcassets/`: native app assets derived from the existing brand.
- `ios/ZotMacrosTests/`, `ios/ZotMacrosUITests/`: native persistence/state tests and accessibility-driven user-flow tests.
- `ios/README.md`, `docs/verification/ios-port/RESULTS.md`: setup and actual evidence, including remaining blockers.

**Interfaces:** Produce Codable/Sendable `Nutrient`, `Nutrition`, `Dish`, `MenuFood`, `MenuPeriod`, `MenuSnapshot`, `Meal`, and `DiaryEntry`, preserving Android field semantics. `Nutrition.scaled(by: Double) throws -> Nutrition`; `aggregate(_ items: [Nutrition]) -> [Nutrient: NutrientTotal]`; `CampusClock.day(at: Date) -> String`; `CampusClock.nextMidnight(after: Date) -> Date`. `NutrientTotal` holds optional value and missing count; `DiaryEntry` includes UUID, campus day, creation timestamp, original Dish, hall/station/period, meal, and quantity.

- [ ] Add package manifest and failing tests: `testUnknownAndZero` asserts a reported zero remains zero and an absent value remains nil; `testPartialTotals` asserts `[20, nil]` yields 20 with missing=1, `[nil]` yields nil, and an empty diary yields zero.
- [ ] Add quantity cases 0, -1, infinity, NaN, 1000.1 rejected; 0.5 and 1000 accepted. Assert scaling 0.1 by 1.5 uses unrounded arithmetic. Add overflow coverage so nonfinite output never becomes a displayed number.
- [ ] Add campus boundary tests with UTC instants around Los Angeles midnight and both DST changes; assert the next midnight is strictly later and on the following campus day.
- [ ] Run `swift test --package-path ios/ZotMacrosCore`; confirm failure from missing implementations, then implement the above interfaces and all 14 nutrient labels/units from Android `Nutrition.kt`.
