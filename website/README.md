# ZotMacros landing page

Static HTML and CSS, with no dependencies, tracking, forms, or hosting service.

Preview from the repository root:

```sh
python3 -m http.server 4173 --directory website
```

Open http://localhost:4173. Android links to the verified v1.0.2 GitHub prerelease. iOS is labeled in development. Images are native simulator development previews with test/example data, identified on the page. The page is not deployed.
